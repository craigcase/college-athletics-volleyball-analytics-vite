# v0.7.0 Rally Analytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic VCSU-first rally analytics engine that ingests PrestoSports, Volleyball LiveStats, and public Sidearm play-by-play into one canonical rally timeline, persists it safely, calculates supported rally metrics, and exposes them through Match Summary and Coach's Edge without inventing unsupported detail.

**Architecture:** Source-specific adapters normalize raw scoring records into one source-neutral timeline draft. A canonical timeline builder converts those records into sets/rallies, inserts gap placeholders, derives serve/receive state and conservative rally pathways, and persists the result by canonical revision. Pure analytics functions consume only the canonical rally state; the UI and Coach's Edge read persisted deterministic results and gate unsupported questions by explicit match capabilities.

**Tech Stack:** Node 22, TypeScript 5.9, React 19, Vite 8, Supabase Postgres/Auth/Storage/RLS, Netlify Functions, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-13-v0.7.0-rally-analytics-design.md`

## Global Constraints

- Base version is v0.6.6 and the package version becomes `0.7.0` only after all implementation tasks pass.
- Visible production data is VCSU 2026 only; historical AUM/UWF rich files are regression fixtures only and never enter VCSU production tables.
- Current source target is public Sidearm box score/play-by-play plus official `vbgame` XML from PrestoSports and Volleyball LiveStats In-Arena Tool.
- Raw bytes must be preserved before parsing; source provenance remains auditable.
- Missing evidence stays missing. Do not infer FBSO-vs-later-sideout, T1/T2/T3+, Good Dig, contact quality, attack origin/destination, or exact on-court personnel from terminal-only PBP. Rule-derived serving/receiving **team side** is allowed when the previous rally winner makes it deterministic; never invent the server-player identity.
- Opponent service error is a successful sideout and is labeled `first_ball_sideout` with `given` attribution and `service_error` terminal event; it is the coaching concept of an unearned FBSO.
- Ace is a serving point with `direct_serve_point` pathway and `earned` attribution; it is not a transition point.
- Serving-team non-ace rally wins may be labeled `transition_point` from ordinary PBP because a serving team cannot earn FBSO.
- Receiving-team non-service-error wins remain `unknown_phase` unless a richer source proves first-ball versus later sideout.
- Score1 and SOS2 use the locked censoring rules: set-ending sideouts without the required subsequent serving rally(s) are censored, not failures.
- EPO uses `given` errors only; a blocked/stuffed attack is not `given`.
- Timeouts are non-scoring timeline events and never receive artificial probability impact.
- Rotation order advances only when a receiving team wins and gains serve; substitutions do not alter slot order. In v0.7.0, serving-cycle slots may be derived, but R1-R6 is not exposed unless anchored by supported evidence.
- Additive Supabase migration only; no destructive rewrite of v0.6.6 tables.
- Every new table must be covered by authenticated user-scoped RLS.
- Existing local request serialization in `runWithUserAccessToken()` remains unchanged.
- Browser code never receives service-role access.
- Normal verification command is `npm run verify`; production/dev smoke test is `npm run dev`.
- Generated `dist`, `node_modules`, `.core-dist`, and `*.tsbuildinfo` are never committed.
- Retire the old GSC/conference benchmark concept completely; do not add conference tables, routes, or UI.

- [ ] **Step 3: Implement producer detection**

Use the `<vbgame ...>` root attributes only:

```ts
export function detectVbgameProducer(xml: string): VbgameProducer {
  const root = xml.match(/<vbgame\b[^>]*>/i)?.[0] ?? '';
  const source = attrs(root).source?.trim().toLowerCase() ?? '';
  if (source === 'prestosports') return 'presto_vbgame';
  if (source.includes('volleyball livestats')) return 'livestats_vbgame';
  if (source.includes('genius')) return 'genius_vbgame';
  return 'unknown_vbgame';
}
```

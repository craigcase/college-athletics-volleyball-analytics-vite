# Static Local Development Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Replace the embedded Vite runtime with a single plain Node server that serves the built React app and the existing API handlers on port 5173.

**Architecture:** Vite is build-only locally. `npm run dev` runs a client build, then launches `scripts/local-dev-server.ts`. The Node server dispatches `/api/*` directly to the existing handlers and serves `dist/` with SPA fallback for everything else.

**Tech Stack:** Node 22 HTTP server, TypeScript/tsx, Vite 8 build, React 19, Supabase, Netlify Functions.

**Spec:** `docs/superpowers/specs/2026-09-12-static-local-dev-server-design.md`

## Global Constraints

- One local HTTP port: 5173 by default.
- No Vite runtime middleware or proxy.
- Existing API handlers remain the only server-side business logic.
- Netlify production routing remains unchanged.
- GitHub remains the source of truth; generated build artifacts are not committed.

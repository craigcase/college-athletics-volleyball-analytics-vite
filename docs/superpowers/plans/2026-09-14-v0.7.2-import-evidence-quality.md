# v0.7.2 Import & Evidence Quality Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build immediate match import review, trusted program-specific aliases, richer Sidearm extraction, evidence-quality reconciliation, reversible staff corrections, and a compact deep PBP/Data Quality inspection surface without weakening the existing deterministic analytics trust model.

**Architecture:** Preserve the existing source adapters and raw-artifact storage. Add a reconciliation layer that ranks match candidates, resumes a preserved import after authorized confirmation, audits timeline facts against source totals, overlays staff-confirmed canonical overrides at read time, and exposes quality/review records through focused APIs. The UI remains coach-first: match identity review is blocking; statistical uncertainty is visible but non-blocking; deep PBP/Data Quality stays secondary.

**Tech Stack:** Vite + React 19 + TypeScript 5.9 + Supabase Postgres/Auth/Storage/RLS + Netlify Functions + Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-14-v0.7.2-import-evidence-quality-design.md`

## Global Constraints

- FAST. EASY. EFFICIENT.
- Evidence first; missing evidence stays missing.
- Raw source artifacts and parsed observations are immutable.
- Authority: staff-confirmed override > official/richer structured source > public website > uniquely reconciled derived fact > unresolved.
- Public Sidearm/Presto is not a contact-by-contact source; do not invent contacts, transition depth, court location, or exact on-court state.
- Match identity ambiguity is blocking; statistical uncertainty after identity is normally non-blocking.
- Staff corrections must be reversible and auditable; reason is optional.
- v0.7.3 coach notes/highlights/Film Room behavior is deferred.
- Re-imports must remain idempotent.
